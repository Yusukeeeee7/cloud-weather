# dev-log：作業ログを記録する

## 手順

1. このセッションの会話、`git log` と `git diff main...HEAD`、`/review` の結果を振り返る。
2. `docs/dev-log.md` のテンプレートに沿って、新しいエントリを **末尾に追記** する（テンプレート自体は残す）。
3. 次の項目は **事実だけ** を書く：
   - 指示したこと（人間のプロンプトの要約）
   - 渡したコンテキスト（CLAUDE.md、使った skill、明示されたファイル、足りなかった情報）
   - TDD（先に書いたテスト、Red を確認したか、最初の実装で通ったか、修正回数）
   - AIの誤り・ハルシネーション（内容、気づいた仕組み、修正、再発防止）
   - セキュリティ上の確認
4. **自分では分からない項目は空欄にし、`（要記入）` と書く**：
   - Claude の利用量・金額（人間が確認して記入する）
   - 人間が気づいた誤りで会話に出ていないもの
5. 再発防止として CLAUDE.md や skills を変えるべき点があれば、変更案を提示する（勝手に変更しない）。
6. 人間に `（要記入）` の箇所を埋めるよう伝える。

## 守ること
- 誤りを隠したり小さく書いたりしない。面接では誤りとその対処が一番の材料になる。
- 数値は推測しない。分からなければ空欄。
